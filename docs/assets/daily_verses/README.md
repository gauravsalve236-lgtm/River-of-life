# Daily Bible Verse Images / रोजच्या वचनाचे वॉलपेपर फोल्डर

Drop your Daily Bible Verse background images directly into this folder (ssets/daily_verses/)!

### Supported Image Formats:
- .png
- .jpg / .jpeg
- .webp

### How It Works:
- The app automatically rotates through images in this folder for the Daily Bible Verse card.
- Users can also switch wallpapers on the fly using the wallpaper chips in the app.
