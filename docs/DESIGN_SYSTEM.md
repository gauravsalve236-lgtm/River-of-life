# River of Life — Visual Design System

## Direction
Premium, calm, prayerful, modern and welcoming. The app should feel like one product from Today through Bible, Prayer, Meetings, Church and Profile.

## Brand language
- Primary: deep river green for navigation, primary actions and trust cues.
- Secondary: warm gold for Scripture, worship and highlights.
- Surfaces: warm off-white and white rather than cold gray.
- Meeting mode: deep forest/near-black with subtle green depth and restrained gold accents.

## Typography
- UI: Outfit for headings, navigation and controls.
- Utility/body UI: Inter.
- Scripture and devotional prose: Lora.

## Components
Use one shared treatment for cards, buttons, segmented controls, drawers, modals, inputs, empty states, loading states and error states. Prefer 12–24px radii, restrained borders, soft elevation and clear focus states.

## Home
Scripture hero → Continue Reading → Prayer Pulse → next Prayer Meeting → Church Companion → Quiz → Reading Plan → Quick Actions.

## Bible
Scripture is the visual priority. Keep controls quiet and typography generous. Verse actions should use a consistent bottom/action sheet pattern.

## Prayer
Use warm, human cards. Make privacy and state visible without making the screen feel administrative.

## Meetings
Use a true meeting-room canvas: active speaker first, participant grid, compact status badges, bottom control bar, optional right/slide-up panels for Chat, People, Bible, Prayer and Share. Mobile controls must respect safe-area insets.

## Responsive rules
- Desktop: sidebar navigation and generous content width.
- Tablet: compact sidebar or hybrid navigation.
- Mobile: bottom navigation, full-width cards, large touch targets, safe-area padding.
- Never simply shrink desktop UI onto mobile.

## Accessibility
Maintain visible focus states, sufficient contrast, keyboard operation, reduced-motion support, and touch targets appropriate for phones.
