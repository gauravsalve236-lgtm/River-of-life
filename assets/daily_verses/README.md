# 🖼️ Daily Bible Verse Wallpapers / दैनिक वचनाचे वॉलपेपर फोल्डर

या फोल्डरमध्ये तुम्ही तुमच्या आवडीचे कोणतेही आउटसोर्स केलेले (Pinterest, Unsplash, Google, Pexels, WhatsApp किंवा स्वतःचे) वॉलपेपर/फोटो थेट अपलोड करू शकता. **कोणताही कोड बदलण्याची गरज नाही!**

---

## 📁 GitHub वरील फोल्डरचा मार्ग (Directory Path):
```text
assets/daily_verses/
```
*(टीप: जर GitHub Pages वापरत असाल तर `docs/assets/daily_verses/` मध्ये देखील तीच फाईल ठेवावी.)*

---

## 🚀 नवीन फोटो ॲपमध्ये आणण्याचे २ सोपे मार्ग (2 Simple Ways):

### मार्ग १: शून्य-कोड थेट नाव (Zero-Code Drop-in) — सर्वात सोपे!
कोणत्याही कोड किंवा JSON फाईलला हात न लावता, तुमच्या आवडत्या फोटोचे नाव खालीलपैकी एका नावाने सेव्ह करून या फोल्डरमध्ये अपलोड करा:
- `today.jpg` किंवा `today.png`
- `custom.jpg` किंवा `custom.png`
- `daily_verse_custom.jpg` किंवा `daily_verse_custom.png`

👉 **ॲप आपोआप या नावाचा फोटो शोधून सर्वात आधी रोजच्या वचनावर सेट करेल!**

---

### मार्ग २: कायमस्वरूपी यादीमध्ये जोडणे (Add to Manifest)
जर तुम्हाला अनेक फोटो कायमचे साठवायचे असतील:
1. तुमचा फोटो `assets/daily_verses/` आणि `docs/assets/daily_verses/` मध्ये अपलोड करा (उदा. `my_scenic_mountain.jpg`).
2. या फोल्डरमधील `manifest.json` फाईल उघडून त्यात `"images"` यादीत फक्त तुमच्या फोटोचे नाव जोडा:
```json
"images": [
  "my_scenic_mountain.jpg",
  ...
]
```

---

## 🎨 शिफारस केलेले फोटो तपशील (Recommended Image Specs):
- **प्रमाण (Aspect Ratio)**: ९:१६ (उभा / Vertical Mobile Status - 1080×1920 px)
- **स्वरूप (Format)**: `.jpg`, `.jpeg`, `.png`, `.webp`
- **शैली (Style)**: निसर्गरम्य दृश्ये (पर्वत, सूर्योदय, समुद्र, शांत कुरणे, धुक्यातील रस्ते) जेणेकरून सोनेरी व पांढरे वचन त्यावर सुंदर आणि स्पष्ट दिसेल.
